# 단청 문양 타일 · 아이콘

## 출처와 라이선스

원본은 저장소의 `Attachments/dan/` 에 있는 Pngtree 자산이다.
사용자가 **Pngtree 개인회원** 라이선스로 내려받은 파일이라고 확인해 주었다(2026-07-31).

주의: Pngtree 개인 라이선스는 통상 '개인' 사용 범위다. 사찰 공식 홈페이지는
단체 명의이므로 플랜에 따라 범위가 갈릴 수 있다. 정식 오픈 전에 계정의
라이선스 상세를 확인할 것.

## 어떻게 만들었나

원본은 1200x1200 PNG 안에 가로 띠 문양이 3~4개씩 쌓여 있는 형태다.
그대로는 반복 배경으로 쓸 수 없어, 띠마다 **가로 반복 주기를 계산해** 한 단위만
잘라냈다(뇌문 270px, 태극격자 271px, 반원 연꽃 65px — 자기 자신과 91~93% 일치).
잘라낸 단위를 이어 붙여 이음매가 없음을 확인했다.

색은 원본의 진하기를 알파로 옮기고(선 굵기·안티에일리어싱 보존) 팔레트 색으로
다시 칠했다. 그래서 원본 24KB → 타일 800바이트 수준이 된다.

`-faint` 는 같은 문양의 알파를 10% 안팎으로 낮춘 배경용 타일이다.
가장 진한 잉크가 알파 상한이 되도록 먼저 정규화한 뒤 낮춘다. 그냥 명도를
알파로 쓰면 갈색 잉크(명도 104)가 56% 로 눌려 문양이 흐려진다.

| 파일 | 크기 | 최대 알파 | 용도 |
|---|---|---|---|
| `dan-band.png` | 270x128 | 230 | 뇌문. 진한 구분선용(현재 미사용) |
| `dan-band-soft.png` | 270x128 | 46 | 뇌문 중간 농도(현재 미사용) |
| `dan-band-faint.png` | 270x128 | 26 | **최상단(.topbar) 배경** |
| `dan-band-taegeuk.png` | 271x148 | 217 | 태극격자 진한 판(현재 미사용) |
| `dan-taegeuk-faint.png` | 271x148 | 17 | **대메뉴(.mainbar) 배경** |
| `dan-arc-faint.png` | 65x115 | 25 | **푸터(footer.site) 배경** |
| `icon-cloud.png` | 206x135 | 255 | 구름 원색(현재 미사용) |
| `icon-cloud-faint.png` | 206x135 | 35 | **정기법회 패널 모서리 워터마크** |
| `icon-flower.png` | 164x164 | 255 | 꽃 문양(현재 미사용) |
| `icon-fret.png` | 100x114 | 255 | 뇌문 사각(현재 미사용) |

아이콘은 띠 안의 문양을 연결 요소로 분리해 잘라내고 흰 배경을 투명으로 바꿨다.

## 쓸 때

- 띠는 반드시 `repeat-x` 로. 세로로도 반복하면(`repeat`) 가로 줄무늬가 되어
  본문 가독성을 해친다. 전면 배경에는 쓰지 말 것 — body 의 금색 점무늬가 그 역할이다.
- **문양은 배경으로만 쓴다.** 제목 밑 장식이나 가장자리 띠처럼 전경에 얹으면
  화면이 산만해진다(2026-07-31 사용자 확인).
- **인접한 영역에 같은 타일을 쓰지 말 것.** 최상단·대메뉴·푸터에 같은 뇌문을
  깔았더니 경계가 끊긴 한 장처럼 보여 어색했다. 지금은 뇌문/태극격자/반원으로 나눴다.
- 높이는 `auto 100%` 로 맞춘다. 픽셀 값으로 고정하면 화면폭에 따라 잘린다.
- 글자 뒤에 깔 때는 **가장 어두운 문양 픽셀 기준**으로 대비를 잰다.
  현재 최악값(실측): 최상단 5.34:1, 대메뉴 4.86:1, 푸터 5.42:1 (보조 텍스트 기준, 기준 4.5:1).
  태극격자는 대메뉴 배경 그라데이션과 겹쳐 처음 알파 26 에서 4.58:1 까지 떨어져 17 로 낮췄다.

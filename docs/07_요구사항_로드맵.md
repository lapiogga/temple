## 단계별 로드맵

### 1차-A — 공개 초안 (완료 · 토 7/25 배포)
- [x] 공개 사이트: 소개·대웅전 산신도·가람 중창기·오시는 길(주소+지도링크)
- [x] 사찰 소식: 목록/상세 + 관리자 CRUD(작성·수정·공개토글·삭제), 홈 DB 연동
- [x] 보안 헤더·noindex·robots, 로그인 rate-limit(배포설정), 자체서명 HTTPS(테스트)
- [ ] devbox 배포(systemd+Nginx+self-signed) — 목~토

### 1차-B — 개인정보 없는 콘텐츠 기능 (차주~, 도메인과 함께)
개인정보 미수집 → 컴플라이언스 부담 없이 비교적 빠르게 추가 가능.

1. **히어로 배경 이미지 자동 회전** (#20)
   - 랜딩 상단 배경에 여러 컷 이미지 자동 슬라이드(페이드/크로스페이드), 접근성(모션 최소화 존중).
   - **선행: 실사진 확보**(대웅전·경내·사계절 등).
2. **법회·행사 캘린더** (#18)
   - **캘린더 기본 + 목록 병행 토글**, **월 단위 이동**, 행사 클릭 시 **상세보기**.
   - events 관리자 CRUD(등록·수정·삭제). 정기법회(음력 초하루·재일 등) **음력 반복 계산** 필요.
3. **갤러리** (#5)
   - **관리자 등록**(앨범/사진), 공개 열람. **이미지 업로드**(S3 또는 로컬) 필요.
4. 콘텐츠 확정 반영, **도메인 + 정식 HTTPS(certbot)**, 파비콘/OG.

### 2차 — 회원·커뮤니티 (수 주 · 외부연동·검수·법요건)
개인정보 수집 → 사찰이 **개인정보처리자**. 방침·동의·안전조치 의무.

1. **회원가입/로그인** (#4)
   - **휴대폰 본인인증** + **SNS 간편인증(카카오/네이버)** + **종무소 승인제**.
   - 수집 항목: **성명·생년월일·성별·휴대폰(필수)**.
2. **게시판** (#4): **회원 전용 글쓰기**, 공개 열람(정책 결정).
3. **묻고답하기(Q&A)** (#6, #19): **비회원도 휴대폰 본인인증 후 글쓰기**, **비밀글 선택**, **관리자 답글**.
4. 권한체계(공개/회원/관리자 DB레벨 강제), 개인정보처리방침·수집동의 UI·암호화·접근통제·보관/파기.

## 2차 착수 시 필요한 결정 (지금 아니어도 됨)
1. **본인인증 방식**: (a) SMS OTP 자체(번호 소유 확인, 며칠·저비용) vs (b) 정식 본인확인기관 연동(실명확인, 계약·심사 수 주·유료).
2. **SNS 로그인 범위**: 카카오 / 네이버 / 둘 다 / 생략.
3. **개인정보 처리**: 수집항목 최소화 검토, 처리방침·동의 문구(법률 검토 권장).
4. **갤러리 이미지 저장**: S3(내구성·백업 유리) vs EC2 로컬.
5. **게시판 공개범위**: 회원 전용 열람 vs 공개 열람·회원 글쓰기.

## 사용자 준비물 (2차 선행)
- 휴대폰 본인인증 서비스 계약(정식 방식 택 시) / 문자 발송 API 계정(SMS OTP 택 시)
- 카카오·네이버 Developers 앱 등록(소셜 로그인 택 시)
- 개인정보처리방침 내용 확정(법률 자문 권장)
- 종무소 승인 담당·절차 정의

# 응선사 홈페이지 — 토요일(7/25) 인터넷 초안 배포 실행계획

> 작성: 2026-07-22(수), 감독관(오케스트레이터). 근거: 5축 병렬 분석 워크플로(공개프론트·관리자·배포/인프라·보안·콘텐츠) + 응선사 실자료(`05_응선사_콘텐츠_자료.md`).
> 판정: **조건부 실현 가능**. 두 선행조건(① 도메인/HTTPS, ② 응선사 실제정보)이 목요일까지 풀리면 토요일 초안 공개 가능.
>
> **확정된 결정(2026-07-22, 사용자 #16)**:
> 1. **인프라**: 신규 EC2 미기동 → **기존 kq-devbox-dev에 배포**(차주 kis_quant 분리 여부 결정). devbox엔 이전 검증 때 PostgreSQL 16·스키마·운영자 시드 구축됨 → 인프라 리스크 대폭 감소. **단, devbox 기존 서비스(kis_quant) 무중단 원칙 — 변경 전 상태 확인 필수.**
> 2. **도메인/HTTPS**: 도메인은 **차주 확보 시 설정**, 당분간 **테스트 용도**. 이번 주는 secure 쿠키 로그인 보장을 위해 **자체서명(self-signed) HTTPS**로 devbox 공개(브라우저 경고 감수). certbot 정식 HTTPS는 차주 도메인과 함께.
> 3. **콘텐츠**: 미확정(계좌·전화·법회 실제일정 등)은 **'준비 중' 숨김**. 확정 시 관리화면/재배포로 반영.
> 4. **범위**: **소식만 DB연동** + 행사·중창기·갤러리 하드코딩 유지 + **noindex**. 8월말 정식 오픈.
>
> → 이에 따라 §2 일정의 "신규 EC2 프로비저닝"은 **devbox 배포 준비**로 대체, "Route53+certbot"은 **self-signed HTTPS**로 대체.

## 0. 핵심 전략
- **"소식(notices) 한 축만 진짜로 살리고 나머지는 하드코딩 유지"**. 데이터레이어(`src/lib/notices.js`)·admin CRUD는 이미 완성. 그러나 공개 `page.js`가 `"use client"` + 상수 하드코딩이라 **운영자가 소식을 써도 홈에 반영되지 않음** → 이 연결이 초안의 존재 이유이자 최우선 개발과제.
- 미완성 도메인(행사·중창기·갤러리)은 **검색엔진 noindex**로 가리고 8월말 1차에 정식 오픈.
- 미확정 응선사 정보(계좌·전화·일정)는 **'준비 중'으로 숨김** — 가짜정보·사찰 사칭 리스크 원천 차단.

## 1. 초안 배포 범위
### Must-have (토요일 전 필수)
1. `page.js` server component 전환 + 소식 섹션 `listNotices()` DB 연동(인터랙션 로직은 작은 client 서브컴포넌트로 분리)
2. `/notices` 목록 + `/notices/[id]` 상세 신설 → '소식 전체 보기' 깨진 링크 해결, 본문 `white-space:pre-line`
3. 깨진 `href="#"` 3곳(중창기 전체보기·개인정보처리방침) 정리
4. placeholder(○○사/○○산/전화/계좌/example.kr) → 응선사 실제값 전면 치환. 미제공은 '준비 중' 숨김
5. robots **noindex** + `public/robots.txt`
6. `next.config.mjs` 보안헤더(X-Frame-Options:DENY, X-Content-Type-Options:nosniff, Referrer-Policy)
7. Nginx `limit_req`(로그인 무차별 방지) — 방화벽 개방보다 먼저 반영
8. 신규 EC2 + EIP + 보안그룹(80/443 배포일만 개방, 22 관리자IP, 5432 비공개) + PostgreSQL/Node/Nginx
9. 실서버 `.env`(강한 SESSION_SECRET·DB비번) + db:init + db:seed(운영자 1계정) + systemd active
10. HTTPS: 도메인+certbot, 미확보 시 **self-signed 임시**(secure 쿠키 때문에 HTTPS 없으면 로그인 자체 불가)
11. 응선사 한자 應禪寺 확정, 부암동 백석동길 227 주소, 대웅전 산신도(서울문화재자료 제14호) 소개
12. 1페이지 운영자 매뉴얼 + 자격증명 안전 전달
13. 모바일 실기기 검증 1회 + 소식 작성→공개→홈 노출 수동확인

### Deferred (8월말 1차로 연기)
행사/정기법회/중창기 DB연동·전용 CRUD · 갤러리·법문 페이지 · 자체 이미지 업로드(당분간 외부 https URL) · 카카오맵 SDK(주소+외부링크로 대체) · 실사진 수급 · 웹폰트 최적화 · favicon/OG · 리치텍스트 · HSTS/세밀 CSP · S3 백업·CloudWatch·CI 무인배포 · 창건연혁 사료 확정 · 온라인 결제

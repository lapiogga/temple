## 한 줄 요약
응선사(應禪寺) 온라인 도량. **Next.js 14 App Router · JS · PostgreSQL · kq-devbox-dev**. 목표: **토요일(7/25) 인터넷 초안(리뷰) 배포**. 기능은 리뷰 준비 완료(당일 **9커밋**), **5축 보안 감사 16건 전부 조치 완료**.

## 실행 방법
- 경로: `/data/projects/temple` (심링크 `/home/ubuntu/projects/temple`)
- DB: 로컬 PostgreSQL `temple` 구동 중. `.env` 에 `DATABASE_URL`·`SESSION_SECRET`·`NEXT_PUBLIC_KAKAO_MAP_KEY`(실키, 단 카카오 앱에 도메인 미등록 → OSM 폴백)
- 빌드·구동: `cd /data/projects/temple && npm run build && NODE_ENV=production npm run start` → `127.0.0.1:3000`
- 서버 재기동 패턴: `fuser -k 3000/tcp; nohup env NODE_ENV=production npm run start > /tmp/.../temple-server.log 2>&1 &`
- DB 초기화 `npm run db:init` · 운영자 시드 `npm run db:seed -- <id> <pw> <name>`

## 핵심 결정 (누적)
- 인프라: 신규 EC2 미기동, **기존 kq-devbox-dev 사용**(차주 kis_quant 분리 결정)
- HTTPS: 도메인 차주. 당분간 테스트용 → 배포 시 **self-signed HTTPS**(secure 쿠키 로그인 위해 필수)
- 미확정 정보는 **'준비 중' 숨김**, **noindex**(초안 색인 차단)
- 게시판: **열람 공개·작성 회원·작성자 닉네임(실명 비공개)**
- 본인인증(가입/Q&A): **리뷰용 클라이언트 데모**(SMS 미연동, 화면 명시). 실서비스 시 교체
- SNS 로그인: 준비 중(스텁). 리치에디터: `react-quill-new` + 본문 `sanitize-html` allowlist. 인라인 이미지 버튼 제거(업로드 방식 후속)

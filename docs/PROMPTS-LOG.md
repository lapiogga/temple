`events.starts_at` 은 성격이 달랐다. 관리자가 친 벽시계가 UTC 라벨을 달고 저장돼 있어
(18:00 입력 → 18:00+00, 실측 확인) KST 로 읽으면 9시간 밀린다. 순간은 KST, 벽시계는
UTC 로 **명시 고정**했다. 서버가 UTC 라 후자는 표시값이 안 바뀐다 — 데이터 이전 불필요.

`EventForm` 은 클라이언트 컴포넌트라 브라우저(KST)에서 다시 계산되는데 로컬 게터를

1. nginx 리미터를 `return 200` 으로 쟀는데 안 걸렸다. `return` 은 rewrite 단계라
   preaccess 의 `limit_req` 보다 먼저 끝난다. 정적 파일로 바꿔야 전체 단계를 탄다.
2. `format.js` 를 인라인으로 베껴 테스트했다가 null 가드를 빠뜨려 코드 결함으로 오인했다.
   실제 모듈을 import 하니 전부 통과였다.
3. 파비콘 SVG 는 **렌더해 봐서** 파싱 오류를 잡았다. 주석에 토큰 이름을 적었더니 `--` 가
   들어가 XML 주석 규칙을 어겼다. 파일만 읽었으면 깨진 채 나갔다.

### nginx 가 조용히 실패한다

`nginx -t` 통과 + reload 종료코드 0 인데 운영은 옛 설정 그대로였다. reload 는 공유 메모리
zone 을 이름으로 재사용하면서 키가 같기를 요구하는데, 이름을 두고 키만 바꿔서 `[emerg]` 로
적재에 실패하고 master 가 옛 설정을 유지한 것이다. `nginx -t` 는 돌고 있는 인스턴스를
모르니 못 잡는다. 로그를 읽을 권한이 없어 **격리 nginx 로 같은 전이를 재현해** 메시지를 얻었다.

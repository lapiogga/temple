위치 · 기와지붕

기본(먹색) + 강조(석간주/뇌록 배경) 두 가지 표시 예시. 동일 path를 크기만 바꿔 16~48px로 사용 가능.

중창기 타임라인 템플릿

연도별 마디(노드) + 내용 + 사진 자리. 항목을 반복 배치하는 구조. 텍스트·연도는 예시 자리표시입니다.

노드 색을 석간주/뇌록 번갈아 사용해 시기 구분에 리듬을 줌. 우측 박스는 전/후 사진 자리(없으면 생략). 항목 1개당 높이 100px 간격으로 추가.

가람배치도 템플릿

상→하로 일주문에서 대웅전까지 중심축 배치(예시). 실제 가람에 맞춰 전각·위치 조정.

주불전(대웅전)만 석간주 톤으로 강조, 부속 전각은 면색으로 통일. 중심축 점선과 방위표로 가람의 좌향(坐向)을 표현. ※ 배치는 예시 템플릿입니다.

사찰 홈페이지 디자인 자산 시안 · 모든 그래픽은 SVG(벡터)로 색·크기 무손실 조정 가능 · 컬러는 CSS 변수(:root) 한 곳에서 일괄 변경 · 시안용 텍스트/연도/배치는 실제 자료로 교체 필요.
